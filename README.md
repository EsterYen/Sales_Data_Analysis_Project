# Sales Performance Analysis Using Python

## Project Overview
This project analyzes sales data to identify product performance and regional sales trends.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Data loading and cleaning
- Exploratory data analysis
- Product sales analysis
- Regional sales analysis
- Data visualization

## Key Insights
- Compared sales performance across products
- Identified regional sales differences
- Created visualizations to support business decisions
